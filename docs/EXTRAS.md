# Дополнительные сценарии: Д3, Д5, Д9, Д11, Д12

Демо-пароль всех аккаунтов: `demo`.

| Сценарий | Где смотреть | Как проверить |
|---|---|---|
| **Д11 Навигатор для новичка** | `/api/public/navigator` (без входа; ссылка на экране входа) | Открыть в режиме инкогнито: дисциплины, шаги, ближайшие соревнования и организации подтягиваются из БД |
| **Д9 Кабинет министерства** | вход `ministry@fsp56.ru`, роль «Министерство» | Видны главная, соревнования, рейтинг, сборная, документы (реестр, численность, приказ), организации. Любая запись возвращает 403 (проверка на сервере) |
| **Д12 Документы о судействе** | «Документы» → блок судейства (Федерация, Судья, Министерство) | Справка о составе коллегии по соревнованию и отчёт по судье, DOCX и XLSX. Судья получает только свои данные |
| **Д5 Апелляции и нарушения** | пункт «Апелляции» | Спортсмен/тренер подаёт апелляцию на свой результат → Федерация принимает решение с обоснованием (можно указать новое место: протокол и рейтинг пересчитаются, уходит вебхук). Федерация/судья фиксируют рапорт → санкция: предупреждение, техническое поражение, дисквалификация (спортсмен пропадает из рейтинга). У каждого дела статусы, история и уведомление заявителю (кабинет + Telegram) |
| **Д3 Организации, группы, журнал** | пункт «Организации» | Карточки организаций с лицензией и программами; группы по этапам подготовки; зачисление и перевод между группами; журнал занятий (очно/онлайн, для онлайн обязательна ссылка на запись или лог) с посещаемостью. Численность по группам попадает в отчёт о численности (JSON и XLSX) |

## API
`POST /api/appeals`, `GET /api/appeals/list`, `POST /api/appeals/{id}/decide`, `POST /api/violations`, `GET /api/violations`, `POST /api/violations/{id}/decide`,
`GET /api/organizations`, `POST /api/organizations`, `GET|POST /api/groups`, `GET /api/groups/{id}`, `POST /api/groups/{id}/members|transfer|sessions`,
`GET /api/documents/judges/composition?competition_id=`, `GET /api/documents/judges/{id}/report`, `GET /api/public/navigator`, `GET /api/public/organizations`.

## Модель данных (миграция `006_extras.sql`)
`organizations` → `training_groups` → `group_members` (история зачислений, `left_at`) и `training_sessions` → `session_attendance`;
`appeals`, `violations`, `case_history` (история статусов по делам).

## Д4, Д6, Д7, Д8, Д10 (миграция `007_norms_bonuses.sql`)
| Сценарий | Где | Как проверить |
|---|---|---|
| **Д4 Нормативы и аттестация** | пункт «Нормативы» (Федерация, Тренер) | Справочник нормативов по этапу/дисциплине (редактирует Федерация, пороги демонстрационные). Внести результат — платформа сама сравнивает с порогом. Таблица аттестации показывает «выполнено N из M» и кнопку «Оформить перевод» (доступна только если выполнены все). История — в «Мой путь» спортсмена и у тренера |
| **Д8 Премии Губернатора** | «Премии и показатели» (Федерация, Министерство) | Автоотбор призёров по протоколам за год, расчёт суммы по справочнику, срок подачи до 1 февраля с обратным отсчётом, статусы ходатайства, пакет DOCX (паспорт/ИНН/СНИЛС — маски) |
| **Д6 Показатели развития** | там же | Динамика численности, организации, соревнования года со статусом и календарным планом; у каждого блока указан источник; можно прикрепить подтверждающий документ |
| **Д7 Личный путь и справочник** | «Путь и справочник» | Текущий и следующий разряд, подходящие соревнования по возрасту/дисциплине, справочник понятий (публично: `GET /api/public/glossary`) |
| **Д10 Справка с QR** | «Путь и справочник» → спортсмен | Формирует справку с номером и QR-кодом, ведущим на публичную страницу проверки `/api/public/verify/{код}` |
