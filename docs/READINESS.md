# Собственный сценарий (Р2): «Готовность к старту»

**Проблема.** Участников часто не допускают или они срываются из-за мелочей, которые видно заранее: закончился разряд, нет согласия законного представителя, не пройден антидопинг-курс, заявка не одобрена. Федерация узнаёт об этом в день старта.

**Что делает платформа.** Для каждого участника соревнования строит чек-лист допуска на данных платформы: нет санкций, возрастная группа на дату старта, дисциплина, заявка одобрена (учитывается срок приёма), антидопинг РУСАДА, согласие представителя для несовершеннолетних, срок разряда раньше старта, привязан тренер. Блокирующие пункты (⛔) не дают допуска, остальные (⚠️) — предупреждения. Показывается процент готовности и список блокеров.

**Кто что видит** (страница «Готовность к старту»): спортсмен — свой чек-лист; тренер — подопечных; федерация — всех участников со сводкой «допущено X из Y» и кнопкой «Напомнить неготовым».

**Автоматические напоминания.** Фоновая задача раз в 6 часов проверяет соревнования ближайших 8 дней и за 7, 3 и 1 день до старта шлёт неготовым участникам уведомление в кабинет и в Telegram (если привязан) с перечнем замечаний. Повторов нет (таблица `readiness_reminders`, миграция `008_readiness.sql`).

**API.** `GET /api/readiness?competition_id=N` (федерация, тренер, спортсмен), `POST /api/readiness/remind?competition_id=N` (федерация).

**Код.** Логика без БД: `backend/internal/readiness` (тесты рядом). HTTP и напоминания: `backend/internal/platform/readiness.go`. Экран: `frontend/src/Readiness.tsx`.

**Как показать.** Войти спортсменом → «Готовность к старту» → выбрать соревнование → видно чек-лист. Войти федерацией → список участников и процент готовности → «Напомнить неготовым» → у спортсмена в «Уведомлениях» (и в Telegram) приходит перечень замечаний.
